# 115 學年度工程進度 3D 島嶼

[開啟工程進度網站](https://hsiang0422-star.github.io/tnmr-115-construction-progress/)

國立臺南特殊教育學校總務處｜115 學年度工程執行進度，以專業 3D 地形圖呈現。

- 六座工程島呈現無障礙斜坡道、性別友善廁所、操場跑道、共融遊具、交通車廊道鋼構及大型巴士專案。
- 地形高度代表各工程完成度；點選島嶼可查看工程說明與關鍵節點。
- 工程進度由公開鏡像載入，每 5 分鐘檢查更新；頁面提供原始工程進度試算表連結。
- 網頁以藍灰與大地色系、清晰地形輪廓及克制光影呈現，供校務工程進度閱覽。
